# Application restyle — registro decisioni condivise

Questo file garantisce che **lo stesso pattern legacy diventi sempre lo stesso componente** in tutti i flussi.
La skill `rebranding` lo legge prima di ogni flusso e lo aggiorna dopo. Se un flusso ha bisogno di una scelta
diversa da quella registrata, va discussa con l'utente e la riga va aggiornata (con data), non duplicata.

## Note sul DS

- `sl-empty-state` (risolto 2026-10-15): `titleText` non dichiarava `attribute: 'title-text'`, quindi l'attributo reale
  era `titletext` e `title-text` (doc, test, demo) veniva ignorato. Ora l'attributo è `title-text`; pagine restyle e
  Code Connect migrati. Il vecchio `titletext` non funziona più.

- `sl-detail-panel` (risolto 2026-10-15): nuova proprietà `contained` (bordo completo, `--border-radius` default
